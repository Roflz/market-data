## Definitions (features_extra.py)

R20 = mean (high - low) of the 20 bars before the signal bar, same contract (= entries R20, verified bit-identical). Block A: retN = (close now - close N bars ago) / R20, N = 1, 2, 3, 5, 10, 20; ret60_volscaled = (close now - close 60 bars ago) / (R20 x sqrt 60). Block B: rsvN = where the close sits in the high-low range of the last N bars (0 = at the low, 1 = at the high), N = 5, 20, 60; prev_close_rsv20 = rsv20 one bar earlier; bars_since_high/lowN = bars since the most recent bar that made the N-bar high/low, divided by N (N = 20, 60); range20_width = 20-bar high-low range / R20. All oriented to the trade: shorts get returns x -1, rsv -> 1 - rsv, bars_since_high <-> bars_since_low.

## Verdict

Drop both blocks for now. No version passes the keep rule (FEATURE_RESEARCH.md 4: total $ improves, at least 60% of
years improve, worst year not worse, holds under both models). AUC and log loss are flat (changes of 0.000-0.003). The only
pooled gain, v1+A+B gbm at +$0.19/trade, improves 6 of 13 years, is not repeated by logit (-$0.15) and is within the
year-to-year noise. On the cost_R <= 0.15 subset both models get worse ($2.28 -> $0.99 logit, $2.29 -> $1.44 gbm).
Run note: gbm runs used OMP_NUM_THREADS=2 (the machine was oversubscribed, and the first attempt ran 75 min with no
result). v1 logit/gbm on all events match the main pipeline exactly (0.6192 / 26,399 / -$0.69; 0.6228 / 33,167 / $0.15).
v1 logit on the subset differs slightly from out/ablation_cost_NQ.csv (8,147 vs 8,141 kept, $2.28 vs $2.36).
